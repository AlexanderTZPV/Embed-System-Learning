# 同花顺盯盘助手 / THS Watch 0.1

Windows 10/11 x64 桌面程序：只读截屏、OCR、量价规则、可选 OpenAI 视觉分析、透明置顶悬浮层、每天一个日志。项目存放在仓库的 `AI_Money/` 独立目录，原有嵌入式学习资料保留。

## 在 G:\AI_Money 安装

1. 把压缩包**内容**解压到 `G:\AI_Money`，确认存在 `G:\AI_Money\main.py`，不要多嵌套一层目录。
2. 安装官方 Windows x64 Python **3.11 或 3.12**，建议包含 Python Launcher 或勾选 Add python.exe to PATH。首次安装依赖需要联网。
3. 双击 `setup.bat`（中文入口 `安装.bat` 也可）。成功后双击 `demo.bat`（或 `演示.bat`），可在没有同花顺的情况下检查界面和日志。
4. 退出演示后双击 `run.bat`（或 `启动.bat`），进入设置，关闭“模拟行情回放”，保存。
5. 打开同花顺并进入附件所示的个股分时页。设置股票代码、保存，再完成下文的区域标定。
6. 点击开始。非交易时段只显示等待；测试时可勾选“忽略交易日历和时段”。真实使用时请关闭此开关。

本项目交付的是**可运行源码及 Windows 安装/打包脚本**，不是已经在你电脑安装的软件，也不包含已验证的 Windows exe。云端无法访问你的 G 盘。无需把 API 密钥发给聊天窗口。

## 如果出现“endencies 不是内部或外部命令”

这是旧版批处理在Windows下的换行/编码兼容问题，不是你操作有误。旧版脚本含UTF-8中文及LF换行；新版统一为ASCII内容和CRLF换行，中文入口只转调英文文件。

1. 关闭旧安装窗口，从GitHub重新下载最新的 `AI_Money-Windows.zip`，不要反复运行旧解压目录里的脚本。
2. 把新包完整解压到 `G:\AI_Money`，选择覆盖程序文件。新版不包含 `runtime`，不会覆盖已有设置、日志和API凭据。不要删除 `runtime`。
3. 确认该目录新增了 `setup.bat`、`run.bat`、`demo.bat`，然后双击 `setup.bat`。完成后双击 `demo.bat`。
4. 若提示 Python 未找到，安装官方64位Python 3.11或3.12，勾选Python Launcher或PATH后重试。
5. 若提示已有 `.venv` 损坏或Python版本不符，先关闭软件，把 `.venv` **重命名**为 `.venv-backup`，再运行 `setup.bat`。无需删除个人数据。

也可以在命令提示符中分行执行，绕过旧版安装脚本：

```bat
cd /d G:\AI_Money
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py --demo
```

如果安装的是3.12，把第一条Python命令中的 `-3.11` 改成 `-3.12`；请确认每一步成功再继续。没有 `py` 但已将正确Python加入PATH时，用 `python -m venv .venv`。

新脚本不要求修改Windows系统编码或切换UTF-8区域设置。控制台提示使用英文，应用界面仍然是中文。

## 为什么“开始”一直显示【演示】？

旧版从 `demo.bat` 启动后，退出、保存设置或拖动窗口都可能把演示开关写入配置，导致下次 `run.bat` 也继续演示。新版已修复：**正常启动始终默认实时，演示选择仅对本次运行有效**，会自动忽略旧配置里的演示标记，保留其他配置。

- **实时监控**：用 `run.bat`（或 `启动.bat`）打开，按钮应显示“开始实时监控”。先完成股票代码及区域标定，再点击开始。交易时段外会显示等待，不会自动补成演示行情。
- **演示**：只有明确运行 `demo.bat`（或本次在设置勾选模拟行情并保存），才使用模拟数据，按钮显示“开始演示”，设置页也显示当前数据源。
- **本次从演示切到实时**：点击停止，等待停止完成；在设置 → 监控取消“仅本次运行启用模拟行情”，保存设置，再点“开始实时监控”。
- **重新打开实时软件**：先从设置或托盘选择“退出软件”，再运行 `run.bat`。仅隐藏窗口并没有退出，已有演示实例会继续存在。

切换模式会清除屏幕上的旧结论及旧报价，原有日志仍保留。没有窗口、未标定或OCR失败时，会显示真实的阻塞原因，不会悄悄改用模拟数据。

## 窗口操作

- 常驻控制条：开始/停止、设置、鼠标穿透、透明/新闻区、隐藏。控制条独立于可穿透的内容窗口，始终保留可点击的停止入口。
- 悬浮层之外没有全屏遮罩；结论区默认不透明，适合覆盖左下“个股新闻”。点击“透明/新闻区”可切换半透明，背景透明度可在外观设置修改。
- 拖动面板标题移动；位置自动记忆，尺寸在外观设置修改。“吸附同花顺左下新闻区”按窗口比例定位。
- 每分钟结束后生成一条本地结论，最新在上；最多保留120行。迟到的AI结果更新原分钟位置，不会顶到最新分钟之上。鼠标悬停可看完整数据。
- 关闭设置窗口只隐藏，不退出；托盘菜单或设置里的“退出软件”才结束程序。无托盘环境隐藏后会打开设置，防止找不到控制入口。

## 首次标定（必须）

预填坐标依据附件的**三列布局**，只是起点，不是对任意 DPI、版本的识别准确率保证。设计文档中的右侧区域比例与实际附件不一致，程序采用按客户区比例标定。

1. 停止监控，确保同花顺完整显示在桌面上。
2. 设置 → 区域标定 → 抓取窗口。程序暂时隐藏自己的窗口，再抓取同花顺客户区。
3. 下拉框选择 `identity`，拖框包含同花顺显示的六位股票代码（单行）。
4. 逐个选择 `price`、`volume_total`、`amount_total`、`turnover_rate` 等字段，**只框一个数值**，不要带标签、其他行或另一列。
5. 每次选字段会显示裁剪放大预览；确认只含对应数值，价格、累计总手、累计成交额、换手率最重要。点击测试识别，逐项与屏幕核对，修正阻塞项后才能保存标定。
6. 改变同花顺版式、字体、DPI或窗口纵横比后请重新标定。相同纵横比的缩放使用比例坐标。

如果旧标定得到 `price:null`、原文 `8.98 +0`，是把相邻涨跌也框入了价格。可缩窄原价格框，或使用“恢复新版参考框”：新版 `price` 预填为行情表“最新”右侧的小字价格。恢复只改变当前对话框，须核对、测试及保存后才生效，不会自动覆盖自定义布局。参考坐标仍需在真机微调。

如果“最高”小于“最低”，程序拒绝两项并提示重新框选，不自动交换。成交额低于0.75置信度会置空；类似 `45 4775`、`.49 44` 的歧义文本不会拼接或猜测小数点。缺失字段列在测试结果 `issues`，会限制相应规则；`can_save` 只表示基础校验通过，不代表每个字段都识别正确。

单位：`volume_total` 必须是**手**，`amount_total` 是元，百分比用百分点（38.59%存38.59）。带万、亿的数字会折算。分时均价由累计成交额 / (累计总手 × 100) 计算；不是简单的截图像素估计。

附加字段可在标定下拉框中选取。`main_net` 必须是**带正负号的主力净流入**，流入为正、流出为负；不能把标注“主力净流出”的正数字直接框进来。默认不预填这类有方向歧义的字段。`bid_volume`/`ask_volume` 应是对应买/卖侧合计挂单量，不是随便一档。

代码不匹配、低置信度、明显价格跳变或累计量倒退时，该字段被拒绝。没有可信价格时不产生行情结论。它不会把错误股票或读不到的数值填成0。

## 采样与分析

- 采样默认每3秒，完整分钟关闭后出结论；手动停止不会把当前不足一分钟当作完整分钟输出。
- 使用北京时间（UTC+8）。默认09:15–09:25集合竞价、09:30–11:30及13:00–15:00连续交易；周末和2026年休市日期停采。11:30、15:00会关闭最后一分钟。
- 日历按2026年安排预置，不把调休周末当成交易日。其他年份默认停止，需导入 `{"year":2027,"holidays":["2027-01-01",...]}`（完整当年交易所休市日期）。交易所临时调整也应更新日历。
- 仅当同花顺主窗口在前台时采集。最小化、切换到其他应用会暂停。**不支持后台、锁屏或被其他应用遮挡时仍可靠读取。** 自己的控制条不抢焦点；打开设置窗口时暂停属于预期行为。
- 数据不足、缺失字段不会凭空推断。分钟量比由最近至少3个已知分钟成交增量计算，最多取前10分钟均值；同花顺显示的“量比”是另外的字段，不混用。午休和缺失分钟会重置短期历史。

内置24条规则，阈值和开关可在分析页修改。规则是技术分析启发式，**不是“读过所有书”的训练模型**；不提供命中概率或收益保证。输出“疑似派发”等状态仅表示量价条件组合，不能证实资金主体或意图。

部分规则需要额外输入：五档合计、带方向的资金值、指数涨幅、MACD、新闻、前五日竞价数据、撤单历史。默认截图模板不能提供这些全部数据，因此相应规则会列入 `unavailable_rules` 而不触发。尤其不能从一张截图证明“洗盘”或“拉高出货”。完整条件见 [规则说明](docs/RULES.md)。

## 采集失败：如何定位具体原因

旧版只显示异常类名 `error`，无法区分Windows接口错误和OpenCV图像错误。新版显示“窗口定位 / 屏幕截图 / 加载OCR模型 / OCR识别”等失败步骤、完整库名和实际错误消息；完整堆栈保存在当天 `.log` 中。

1. 停止监控，等待停止完成；保持同花顺个股分时窗口可见。
2. 设置 → 诊断 → **测试采集并生成诊断**。程序暂时隐藏自己的窗口，执行一次真实窗口定位、截屏与OCR，忽略当前是否为交易时段；不会上传或保存截图。
3. 结果显示失败步骤及错误原文，同时保存为 `runtime/logs/capture-check-日期-时间.json`。这份报告不写API配置或密钥；可以提供其中失败步骤的文字用于排查。
4. 若窗口定位失败，核对标题关键字“同花顺”、窗口是否恢复正常显示；若消息明确为权限错误，再检查同花顺和助手的运行权限是否一致，不必无依据地反复重装或修改系统编码。
5. 若为“代码不匹配”或可信价格缺失，在区域标定中重新核对 `identity`、`price` 等字段。若为 `cv2.error`，请保留完整错误消息；仅凭“error”无法判断需要修正哪一项。

窗口枚举时会跳过已失效的单个窗口，排除助手自己的窗口；前台窗口句柄暂时为空时会暂停重试。实际错误未经真机复现前，不将这些加固描述为已解决所有采集失败。

## 每分钟截图、每日日志与 AI 文件交接

默认本地数据目录为 `G:\AI_Money\runtime`，可用 `启动.bat --data-dir "其他绝对路径"` 改变。演示数据独立放在 `runtime\demo`，所有结论都有“演示”标记。

```text
runtime/
  config/app.json                            设置、标定、规则；无API密钥
  logs/2026-10-26.log                         每日一个人类可读日志
  data/ticks/2026-10-26.csv                    每次OCR的数值、置信度和拒绝标记
  data/conclusions/2026-10-26.jsonl            分钟结论、指标依据、来源
  captures/000530/2026-10-26/0931.png          09:31分钟的最后一张可信截图
  captures/000530/2026-10-26/0931.json         同名指标及本地结论
  analysis/000530/2026-10-26/0931.json         外部AI写回（也支持0931.txt）
```

截图、AI结果根目录可在日志与数据页分别指定。各根目录下仍包含“股票代码/日期”子目录，以免切换股票覆盖截图。截图只保存裁剪后的分时与报价区域，排除了顶部账号工具栏及下方新闻/悬浮层；不是全桌面录像。改变版式时需要自行复核截图中是否有敏感内容。

外部AI结果格式示例：

```json
{"minute":"09:31","text":"价格在均价附近震荡，量能不足；资金字段缺失，暂不判断主力意图。"}
```

开启“读取外部 Agent 写回的文件”后，程序每次轮询检查大小和修改时间，连续两次稳定才读取，只接受本次监控已产生的分钟。未知分钟不会上屏；外部数据不能改写实测指标、严重度或置信概率。请外部工作流先写临时文件，再原子重命名为 `.json`。同一分钟优先级：外部Agent > 内置API > 本地。所有来源都保留在JSONL和log，界面只显示该分钟优先结果。

**普通 ChatGPT 对话不会自动访问本地文件夹。** 本项目不假装该聊天能监听目录。你可以手动上传截图，或者配置下文的API自动流程，或者让实际有本地文件访问能力的Agent读写上述目录。

截图使用该分钟最后一次成功采集的图像；如果窗口不可信，该分钟可能没有数据。连续失败不会补造历史行情。默认不自动删除历史，避免误删；请定期归档，低于500MB停止存图，磁盘写入失败会明确停止监控。日志每条追加并flush，但不是断电级事务数据库。

## 接入 OpenAI / ChatGPT 模型

1. 分析页开启API，Base URL 默认 `https://api.openai.com/v1`，模型默认 `gpt-4.1-mini`，可改成账号可用的视觉模型或其他OpenAI兼容服务。
2. 在本机设置界面填入 API Key，保存到 Windows 凭据库（keyring）。也可在本机进程配置环境变量 `THS_OPENAI_API_KEY`；不写入配置、日志或压缩包。
3. 默认只传指标与本地判断。只有主动勾选“允许上传裁剪行情图”才附带图片。启用API本身意味着允许发送该分钟指标。不同提供商会有自己的存储与计费政策。
4. 每分钟至多发起一次，无重叠请求积压。连接超时3秒、读超时8秒；连续失败3次后本轮监控停止调用API，保留本地输出。重新开始监控会重置熔断。

ChatGPT 网页订阅和 OpenAI API 计费独立。云端没有你的API密钥，本次未做真实联网模型分析验收。软件的API测试使用模拟响应，不声称已完成账号连通测试。模型自身可用的知识不等同于本项目拥有整套股票书籍。

## 测试、回放与exe

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ths_watch.replay runtime\data\ticks\2026-10-26.csv replay-output
```

回放使用同一校验/聚合/规则链路，最后未关闭的分钟不计入结论。不要把输出目录设成输入数据目录。

双击 `打包exe.bat` 在 **Windows** 上运行 PyInstaller，输出 `dist\THSWatch\THSWatch.exe`。必须复制整个 `THSWatch` 文件夹；这份仓库不含预编译exe，Linux不能产出可信的Windows桌面打包验收结果。无Python的新Windows机器仍需实际试跑。

当前实现与设计草案的差异及验证范围见 [验收记录](docs/VALIDATION.md)。
