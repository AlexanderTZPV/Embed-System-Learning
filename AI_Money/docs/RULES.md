# 分析依据与限制

这些是可检查的技术分析条件，不是对特定书籍内容的复制、完整训练或投资胜率承诺。量价配合、突破确认、努力与结果的背离等概念可用于解释现象，但仅靠屏幕数据不能识别交易主体。

程序中的 `ths_watch/core.py: RULES` 是真实判据；设置页面展示每条规则、具体阈值与说明。不对OCR的不确定性编造统计置信度，结论中的 `confidence` 为 null；OCR字段本身有模型识别分数，两者不是同一个概念。

| 规则族 | 观察依据 | 最重要的限制 |
|---|---|---|
| 温和放量上涨 | 均价线上方、分钟涨价、量能1.2–2.5倍、外盘占比及资金增量 | 缺资金读数时不宣称该完整组合成立 |
| 疑似拉升后派发 | 近3分钟曾拉升>2%、从高点回落、放量>3倍、日内位置及资金流出 | 组合迹象，不是主力出货的证明 |
| 假突破 | 突破历史局部高点后回落、量能不足 | 分钟收盘样本，不是所有盘中尖峰 |
| 上涨背离 / 抛压减弱 | 价格新高而量递减 / 新低而缩量 | 短历史窗口，不是日线趋势 |
| 缩量回撤 / 缩量阴跌 | 缩量、均价关系、大单读数 / 连续五分钟下跌 | “洗盘”仅为假设，不输出确定性标签 |
| 放量急跌 | 分钟跌幅、放量倍数、挂单失衡 | 可撤挂单不是实际成交 |
| 涨停封单 / 打开 / 接近跌停 | 屏幕直接识别的涨跌停价、挂单、主动成交 | 不硬编码10%涨跌停，适应不同板块前提是正确识别限制价 |
| 挂单成交背离 / 上方压力 / 下方支撑 | 委比、内外盘、合计挂单、资金增量 | 默认五档合计不是从单个报价数值推断 |
| 高位换手 / 交投清淡 | 累计换手、日内振幅位置 | 20%不是适用于所有股票的普适风险阈值，可调整 |
| 竞价偏强 / 竞价异常 | 前五日同期竞价量、撤单历史 | 默认纯视觉模板缺少这些历史字段，因此不触发；不得从成交量反推撤单 |
| 尾盘拉升背离 / 放量下跌 | 14:45后短期涨跌与资金、量能 | 尾盘流动性与收盘集合竞价会改变解释 |
| 大盘相对强弱 | 个股涨幅减对应指数涨幅 | 默认没有指数输入时不可用 |
| MACD转弱 | 数值由正转负、DIFF下穿DEA | 需要标定对应数字；不靠截图凭空计算 |
| 异动信息 | 已验证的公告输入 | 当前未实现新闻全文OCR与时间/股票核验，默认不可用 |

规则会按危险、警告、一般排序，取前两个解释。危险规则命中时排除“温和上涨”“缩量回撤”“买盘支撑”的冲突标签。未命中表示观察不足或未触发，不表示没有风险。规则阈值来自启发式默认值，未经过历史收益回测。

## 字段缺失与数值可靠性

- 数字解析不把字母O擅自改成0，不补小数点，不从两个数值猜哪个是正确的。
- OCR分数低于0.75置空；相邻一分钟内价格跳变超过3%置空（剧烈行情可能被保守拒绝，应复核）。
- 同日累计成交量、成交额、换手率倒退置空，跨日允许归零。
- 分钟历史不跨午休或缺失分钟；至少三个已知分钟增量才计算分钟相对量能。
- 读取的换手率可以超过100%，不把100%作为绝对上限。
- 没有可信价格就没有该次行情样本；缺失数据始终与0区分。

## 如何增加本地知识

可以调整各规则阈值、开关，或在单独开发任务中扩展 `RULES` 和派生指标。不要把未经回测的经验称为统计概率。若希望采用特定书籍，需提供合法可用的摘录及明确条件，再将条件转化为可测试规则；当前项目没有自动爬取或声称读完这些书籍。
