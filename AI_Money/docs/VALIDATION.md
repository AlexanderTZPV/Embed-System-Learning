# 验收记录与交付边界

交付平台目标是 Windows 10/11 x64；本次实际执行环境是 Linux + Python 3.12。云端不能访问用户 `G:\AI_Money`，没有正在运行的同花顺，也没有用户API凭据。

## 已在云端执行

- 安装 PySide6、mss、Pillow、RapidOCR、ONNX Runtime、keyring、requests 和 pytest。
- 自动化测试涵盖交易时段/节假日/时区、中文数字单位、脏数据拒绝、跨日、24条规则命中与缺失字段、阈值覆盖、模拟CSV回放、每日日志/JSONL、重启去重、部分JSONL写入恢复、外部Agent稳定写入及分钟关联、API默认不传图和超时/HTTPS设置、GUI排序与来源优先级。
- 实际加载RapidOCR自带的ONNX模型，对三种字号的合成红色数字图验证读取9.53。**不是附件原图的OCR准确率测试。** 附件原图未作为可读的本地图片文件提供，不以合成fixture冒充。
- 交付入口 `main.py --demo` 以Qt offscreen真实运行12秒，回放至少9个完整分钟，断言截图/sidecar、CSV、JSONL、单日log、危险规则命中、进程正常退出、单实例锁释放。演示数据有明确模拟标记，使用独立目录。
- 全套检查：`QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q`。最终测试数量与结果见同目录 `test-result.txt`。
- 原有嵌入式学习仓库无文件修改。

## 必须在用户Windows电脑验证

- 同花顺窗口发现、Win32物理客户区、不同显示器DPI换算、真实桌面截屏和首轮区域标定。
- 真实界面中价格、总手、成交额、换手等字段OCR准确率。先用测试识别逐项核对。
- 真实交易日持续采样、午休恢复、前台切换、锁屏/最小化时是否按预期停采。
- 托盘、置顶、鼠标穿透、窗口位置记忆；Windows捕获排除API是尽力启用，老系统可能不支持。
- API Key在Windows凭据库的保存以及目标模型/API账户、网络、计费的实际连通性。
- PyInstaller的Windows构建与无Python机器上的exe试跑。

因此本交付可运行及演示，但**不宣称已经在用户Windows电脑部署或完成真实盘中验收**。

## 相对于设计草案，当前未实现或简化的部分

- 不宣称“学习了整套股市书籍”。使用24条启发式条件和可选大模型，不提供收益预测概率。
- 不做半日/全日日结摘要、自动截图清理、规则冷却、危险边框动画、开机自启或全局快捷键。
- 不做完整新闻OCR、逐笔成交聚合、五档挂单自动合计、前五日竞价/撤单历史；缺数据的规则不触发。
- 模拟行情是预设数值与自绘图；本地图像入口用于标定与OCR测试，不是假装附件截图有历史行情。
- 截图保留经过白名单裁剪的分时与报价区域，不做任意隐私区域遮罩；版式变化要先核对隐私。
- 布局只保存一套当前配置，可手动导入/导出，不自动管理多DPI模板库。
- 未实现完整的系统锁屏事件订阅或所有遮挡判定；采用前台窗口、最小化、代码匹配和数值校验保守拒绝。
- 软件不读同花顺进程内存、不注入、不接券商、不自动交易。窗口被遮挡时也不会虚构实时数据。
- 配置原子替换，文件逐条flush；不是fsync级事务存储，不承诺断电绝不丢一条。

这些边界不会被模拟演示或通过的单元测试掩盖；可以在真实Windows验收后继续迭代。
